# Student Assistant
## Опис
Student Assistant - навчальний застосунок-планувальник завдань для
студентів: додавання, перегляд та відмітка виконання навчальних завдань.
## Архітектура
Кросплатформна, гетерогенна система з кількох незалежних клієнтів (веб,
десктоп, нативний C++, аналітика на Python), що обмінюються даними через
спільний файл tasks.json.
## Технології
- React - веб-інтерфейс (Модуль 2)
- Electron / NW.js - десктопна обгортка (Модуль 3)
- C++ / Qt - нативний десктопний клієнт (Модуль 4)
- Python / Flet - аналітична панель (Модуль 4)
## Структура репозиторію
- frontend/ - React-фронтенд
- desktop-container/ - Electron/NW.js-контейнер
- cpp-core/ - нативний C++/Qt-клієнт
- python-analytics/ - аналітичний модуль на Python
- data/ - спільний файл обміну даними tasks.json

## Запуск десктопної версії

1. Завантажити NW.js SDK з офіційного сайту: https://nwjs.io/.
2. Розпакувати архів NW.js SDK у корінь репозиторію.
3. Для збірки проєкту перейти до теки `frontend/` та виконати команду `npm run build`.
4. Для запуску перейти до теки `dist` командою `cd dist` та виконати `../nwjs-sdk/nw.exe .` (шлях до `nw.exe` змінити відповідно до місця розпакування NW.js SDK).


## Файл даних

Файл `tasks.json` розташований у теці `frontend/src/tasks.json`. Він використовується для зберігання списку завдань застосунку Student Assistant.

### Створення файлу

Під час запуску застосунку викликається функція `ensureTasksFile()`.

Якщо файл `tasks.json` відсутній, програма автоматично створює його з початковим вмістом:

```json
[]
```

Порожній масив означає, що список завдань поки не містить жодного запису.

### Використання прапорця wx

Під час створення файлу використовується прапорець `wx` (write exclusive).

Він забезпечує такі умови:
- файл створюється лише тоді, коли його ще не існує;
- якщо файл уже існує, він не перезаписується;
- це дозволяє зберегти наявні дані користувача;
- якщо файл уже існує, операція створення повертає помилку `EEXIST`.

### Таблиця сценаріїв роботи

| Сценарій | Умова | Очікуваний результат |
|---|---|---|
| 1. Файл існує | `tasks.json` уже створений | Наявний файл зберігається без змін |
| 2. Файл відсутній | `tasks.json` не знайдено | Автоматично створюється файл із вмістом `[]` |
| 3. Файл містить завдання | У файлі є збережені записи | Дані залишаються доступними |
| 4. Помилка створення | Немає дозволу на запис або виникла інша помилка | Помилка обробляється та відображається через `StorageStatus` |
